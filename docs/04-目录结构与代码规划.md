## 2. 分层职责

| 层 | 职责 | 禁止 |
| --- | --- | --- |
| api | 参数校验、鉴权、调用 service、组装响应 | 写业务规则、直接拼 SQL |
| services | 业务规则、事务边界、进程调度 | 依赖 FastAPI 对象 |
| adapters | 与外部推理后端交互，产出标准记录 | 写数据库 |
| models/schemas | 持久化映射与传输契约 | 包含业务逻辑 |
| frontend | 交互与展示 | 直接访问文件系统 |

## 4. 关键实现要点

### 4.1 调度器

- 单进程内 `asyncio.Queue` + `asyncio.Semaphore(max_parallel_tasks)`。
- 每个任务启动一个子进程（`asyncio.create_subprocess_exec`，`start_new_session=True` 便于整组终止）。
- stdout/stderr 由协程按行读取：写日志文件、解析 JSON 行进度、推事件总线。
- 看门狗：单 episode 超时（默认 300s）、单任务超时（config.budget）、显存不足（子进程非零退出且 stderr 含 OOM）。
- 服务重启后扫描 `status IN ('running','preparing')` 的任务，标为 `failed` 并提示"服务重启中断"，避免僵尸任务。

### 4.2 Adapter 协议

```python
class BaseAdapter:
    name: str
    allowed_inputs: set[str]

    def prepare(self, ctx: RunContext) -> None: ...      # 校验路径、准备命令、建目录
    def episodes(self) -> Iterator[str]: ...             # 产出待跑 episode 键
    def run_episode(self, key: str) -> EpisodeRecord: ...# 执行并返回标准记录
    def finish(self) -> dict: ...                        # 汇总指标
```

`EpisodeRecord` 统一字段：`steps, success, spl, ne, os, ndtw, tl, latencies, gpu_mem_peak, tokens_peak, frames[], failure_reason`。

- `StreamVLNAdapter`：生成临时 yaml（数据集/切分/窗口/seed/prune 参数），调用外部入口；解析其输出目录中的 `results.json` 与帧图，映射到 `EpisodeRecord`。
- `MockAdapter`：读取 `storage/sample_results/` 下预置的 20 条结果（由 `scripts/make_sample_results.py` 从已有实验目录抽取），按 seed 加入微小扰动，使对比表与曲线有差异且可复现。

### 4.3 因果性校验

两层：

1. 静态：`config_json.allowed_inputs ⊆ model_profile.allowed_inputs`，且模板要求 `depth` 时数据集 `has_depth=1`。
2. 运行时：适配器封装 `ObservationBus`，只暴露 `history()`（下标 ≤ 当前步）；越界访问抛 `CausalityError`，任务标记失败并写审计。

### 4.4 回放实现

- 任务运行期按 episode 落 `frames/{episode_key}.jsonl`（每行一帧元数据）+ `frames/{episode_key}/{idx}.jpg`。
- 回放接口只读文件，按需返回帧索引与区间帧图，前端 Canvas 绘制轨迹与速度曲线，`<img>` 切换帧。
- 记忆叠加：`frames[idx]` 中记录 `window_len / slow_update / tokens_before_prune / tokens_after_prune / ctx_len`，前端画双轴折线。

### 4.5 报告生成

- Markdown 用 `str.format`/模板拼接；CSV 用 `csv` 模块；PDF 用 `reportlab`，中文字体注册内置 CID 字体 `STSong-Light`，避免携带字体文件。
- 图表由后端用 `matplotlib`（Agg 后端）生成 PNG，或直接复用前端 ECharts 导出；默认走 matplotlib 以支持无人值守生成。

### 4.6 启动与打包

```bash
python run.py --port 8080          # 首次自动建库+种子，前端 dist 存在则托管
```

`scripts/package.sh`：`npm run build` → 产物复制到 `backend/app/static/` → 打包 zip（含 `run.py`、`backend/`、`config/`、`static/`、`README`）。
