## 2. 验收判据

功能验收（离线模式，无 GPU、无数据集）：

1. 首次启动自动建库，30 秒内可登录。
2. 登记内置示例数据集并扫描，episode 列表可检索、可看观测时间轴。
3. 生成 smoke 切分，导出因果切片，文件中不存在晚于截止步的帧。
4. 用 Mock 模型创建任务，5 分钟内跑完 20 条，监控页进度、日志、资源曲线正常刷新。
5. 任务完成后指标非空，可对比两个任务，差值列正确。
6. 失败 episode 能自动归因，回放页四区联动，拖动时间轴同步刷新。
7. 导出 Markdown 报告，指标表与失败案例齐全（图表导出未实现，见待办）。
8. 审计日志记录上述关键操作。

在线验收（GPU + Habitat 场景，本机 8×L40S）：

9. 真实 StreamVLN 任务跑通并落逐帧文件：`frames/<episode>.jsonl` 行数等于步数，回放页有轨迹与记忆曲线。
10. 上游脚本不含 `--dump_frames` 时平台正常出成绩，回放降级为「汇总 + 参考路径」并给出提示。
11. 仿真：启动会话 → 前进/转向/停止 → 关闭并释放显存；页面帧率 ≥15 fps。
12. 模型驾驶：面板加载后自动按 4 Hz 出动作，暂停/停止可用，显存不足自动回退手动。
13. oracle 与录制导出：oracle 能走完一条路径并给出 SPL；录制导出 mp4 可下载、帧数一致。

技术验收：

- 因果性校验可被故意违规配置触发（提交返回 1006）。
- 任务取消后子进程确实退出，无残留进程。
- 服务重启后遗留 running 任务被正确标记，外部导入任务不受影响。
- 逐帧解析对缺字段/半行/重复帧容错（端到端数据契约测试已通过）。
- 全部单元测试通过，`metrics`、`split`、`causal_guard` 覆盖率不低于 70%（**未完成**）。

软著验收：

- 源程序 ≥3000 行有效代码（当前约 25600 行），前 30 页 + 后 30 页可导出。
- 说明书正文与截图一一对应，图号连续。
- 名称、版本、功能描述在申请表与说明书、代码页眉三处一致（新名称：码极客具身导航多模态流式评测与诊断平台）。

## 3. 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 真实推理环境不可用 | 无法演示真实结果 | 全程保证 Mock 模式可用，真实模式作为可选 |
| 上游脚本版本漂移 | 适配器参数或结果字段对不上 | 任务前探测能力（如 `--dump_frames`），不一致时降级并写日志 |
| 前端回放性能不足 | 帧切换卡顿 | 帧图按需加载 + 预取相邻 2 帧；逐帧文件上限 600 帧 |
| SSE 在代理后失效 | 监控页无更新 | 提供轮询降级（`?fallback=poll`） |
| SQLite 并发写 | 任务写入阻塞 | WAL + 单写线程 + 批量提交 |
| 仿真与评测抢同一张卡 | 两边都 OOM | 配置层面分卡（`sim.gpu_ids` / `policy.gpu_id`），启动前显存闸门 |
| `--reload` 与仿真冲突 | 引擎线程被强杀、GL 上下文残留 | 文档明示禁止，仿真调试用 `--no-browser` |
| 报告中文乱码 | Markdown 不可读 | 统一 UTF-8 写入 |
| 代码量不足 | 软著被要求补正 | 当前已远超门槛，导出时按有效代码页截取 |

## 6. 已确认决策

1. 软件全称：**码极客具身导航多模态流式评测与诊断平台** V1.0，简称 码极客 NavEval Studio（2026-11-09 由「具身导航多模态流式评测与诊断软件」更名）。
2. 真实接入 StreamVLN 推理，GPU 环境由用户侧提供；离线演示适配器保留，用于无 GPU 环境的功能验收。
3. 前端 UI 组件库采用 Element Plus。
4. 报告输出 Markdown 与 CSV，不实现 PDF。
5. 仿真复用 `habitat_sim` 渲染与 navmesh，不自研物理引擎；模型驾驶与仿真同进程分线程，配置层面分卡。
6. 逐帧回放只依赖"上游按约定落 jsonl"这一条契约，平台不解析上游内部状态；不支持时降级而非报错。
