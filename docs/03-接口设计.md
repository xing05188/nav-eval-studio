# 03 接口设计

## 1. 通用约定

- 前缀：`/api`；前端静态资源由 `/` 托管。
- 编码：UTF-8，`Content-Type: application/json`。
- 鉴权有两种通道，按客户端能力选择：
  1. **请求头**：登录后返回 `access_token`，`Authorization: Bearer <token>`。Token 为 HMAC 签名串，默认 12 小时有效。
  2. **查询参数**：`<img src>`、MJPEG、文件下载拿不到自定义请求头，改用 `?token=<access_token>`（后端 `get_user_allow_query_token` 依赖）。
- 统一响应：

```json
{ "code": 0, "message": "ok", "data": {...} }
```

- 错误码：

| code | HTTP | 含义 |
| --- | --- | --- |
| 0 | 200 | 成功 |
| 1001 | 400 | 参数校验失败 |
| 1002 | 401 | 未登录或 Token 失效 |
| 1003 | 403 | 无权限 |
| 1004 | 404 | 资源不存在 |
| 1005 | 409 | 状态冲突（如任务已在运行、仿真已有会话） |
| 1006 | 422 | 因果性校验失败 |
| 2001 | 500 | 内部错误 |
| 2002 | 503 | 推理后端不可用（GPU/权重缺失） |

- 分页：`?page=1&page_size=20`，响应 `data = {items, total, page, page_size}`。
- 路径安全：所有 `path` 类参数必须落在 `setting.work_dir` 白名单根目录内。
- 长任务：报告生成、备份库导入、仿真导出为同步返回或后台推进，前端按需轮询对应状态接口。

### 2.5 分析与对比

### 2.6 回放

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/replay/{task_id}/{row_id}` | 回放元数据：任务/结果/指令/配置/逐帧/汇总/几何/记忆 |

### 2.7 交互式仿真

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/sim/sessions` | 建会话（`episode_id`、可选 `gpu_id`），立即返回 `loading` |
| GET | `/api/sim/state` | 快照：状态、步数、距离、测地距离、NE、SPL 估计、位姿、轨迹三条线、帧率、录制进度（`?token=`） |
| POST | `/api/sim/actions` | 动作：`forward / left / right / stop / reset` |
| GET | `/api/sim/stream` | MJPEG 第一视角（含画中画）（`?token=`，只推新帧） |
| POST | `/api/sim/policy` | 启用模型驾驶（可选 `model_id`、`gpu_id`），权重后台加载 |
| DELETE | `/api/sim/policy` | 停用模型驾驶并释放显存 |
| POST | `/api/sim/policy/pause` | 暂停/恢复模型驾驶 |
| POST | `/api/sim/oracle` | oracle 自动驾驶开关（沿 navmesh 最短路径） |
| POST | `/api/sim/pip` | 第三视角画中画显隐 |
| POST | `/api/sim/robot` | 机器狗模型显隐 |
| POST | `/api/sim/recordings/export` | 启动会话录制导出（异步编码 mp4） |
| GET | `/api/sim/recordings/export` | 导出状态（进度也在 `/sim/state` 的 `recording.export`） |
| GET | `/api/sim/recordings/export/file` | 下载 mp4（`?token=`） |
| DELETE | `/api/sim/sessions/{session_id}` | 停止会话并释放显存（`current` 表示当前会话） |

权限：`/sessions`、`/actions`、`/policy*`、`/oracle`、`/pip`、`/robot`、`recordings/export`（POST）限 `admin` / `operator`；
`/state`、`/stream`、`recordings/export/file` 走 `?token=` 通道；`GET /recordings/export` 走请求头鉴权。

## 3. 关键接口示例

### 3.1 创建任务

```http
POST /api/tasks
```

```json
{
  "name": "vision_geo_state_spatial_prune_seed42",
  "dataset_id": 1,
  "split_id": 4,
  "model_profile_id": 1,
  "template_id": 4,
  "overrides": { "history_len": 8, "prune_ratio": 0.35, "seed": 42 },
  "priority": 5,
  "note": "消融：视觉+几何+状态"
}
```

响应：

```json
{
  "code": 0,
  "data": {
    "id": 12,
    "status": "queued",
    "progress_total": 1839,
    "config_snapshot": { "modality": "vision_geo_state", "...": "..." }
  }
}
```

因果性预检失败：

```json
{ "code": 1006, "message": "输入 rgb_future 不在白名单 [rgb,depth,pose,action]" }
```

### 3.2 SSE 事件流

`GET /api/tasks/12/events`（`text/event-stream`）

```
event: progress
data: {"done": 137, "total": 1839, "episode": "1776", "percent": 7.4}

event: sample
data: {"step": 137, "gpu_mem_mb": 18342, "latency_ms": 412.5, "tokens": 9216, "ctx_len": 9216}

event: log
data: {"level": "info", "text": "[137/1839] 1776 SR=1 SPL=0.71 NE=3.42"}

event: state

event: done
data: {"status": "succeeded", "metrics": {"sr": 0.5661, "spl": 0.5023, "ne": 4.8626}}
```

`progress` 节流为 ≥500ms 一次；`log` 按行推送并落盘 `storage/runs/task-000012/run.log`。

### 3.4 逐帧元数据契约

`frames/<episode_key>.jsonl` 每行一帧，字段固定如下（Mock 适配器与真实 StreamVLN 适配器共用）：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `idx` | int | 步序号，从 0 开始，按此升序排序 |
| `t` | float | 相对 episode 开始的秒数 |
| `pose` | [x,y,z] | 世界坐标位置（米），与数据集 `reference_path` 同坐标系 |
| `yaw` | float | 偏航角（弧度） |
| `action` | string | `forward / left / right / stop` |
| `latency_ms` | float | 该步决策耗时（毫秒） |
| `window_len` | int | 当前记忆/视觉窗口内帧数 |
| `slow_update` | bool | 该步是否发生慢更新（历史重采样） |
| `tokens_before_prune` | int | 裁剪前 memory token 数（未启剪枝时为 0） |
| `tokens_after_prune` | int | 裁剪后 memory token 数 |
| `ctx_len` | int | 当前 prompt token 数 |

数据来源与跨仓库改动见 [10-真实适配器逐帧回放.md](10-真实适配器逐帧回放.md)。

### 3.7 报告生成

```json
POST /api/reports
{ "task_ids": [12, 13, 14], "format": "md",
  "include": ["summary", "metrics", "failures"], "top_failures": 10 }
```

响应直接返回已生成的产物元数据（`id`、`name`、`format`、`size_bytes`），随后通过 `GET /api/reports/{artifact_id}/download` 下载文件。报告同步生成，无需轮询。
