# 03 接口设计

## 1. 通用约定

- 前缀：`/api`；前端静态资源由 `/` 托管。
- 编码：UTF-8，`Content-Type: application/json`。
- 鉴权：登录后返回 `access_token`，后续请求头 `Authorization: Bearer <token>`；Token 为 HMAC 签名串，默认 12 小时有效。
- 统一响应：

```json
{ "code": 0, "message": "ok", "data": {...} }
```

- 错误码：

| code | HTTP | 含义 |
| --- | --- | --- |
| 0 | 200 | 成功 |
| 1001 | 400 | 参数校验失败 |
| 1002 | 401 | 未登录或 Token 失效 |
| 1003 | 403 | 无权限 |
| 1004 | 404 | 资源不存在 |
| 1005 | 409 | 状态冲突（如任务已在运行） |
| 1006 | 422 | 因果性校验失败 |
| 2001 | 500 | 内部错误 |
| 2002 | 503 | 推理后端不可用（GPU/权重缺失） |

- 分页：`?page=1&page_size=20`，响应 `data = {items, total, page, page_size}`。
- 路径安全：所有 `path` 类参数必须落在 `setting.work_dir` 白名单根目录内。

## 2. 接口清单

### 2.1 认证与用户

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/auth/login` | 登录，返回 token 与用户信息 |
| POST | `/api/auth/logout` | 注销 |
| GET | `/api/auth/me` | 当前用户 |
| POST | `/api/auth/password` | 修改口令 |
| GET | `/api/users` | 用户列表（admin） |
| POST | `/api/users` | 新增用户（admin） |
| PATCH | `/api/users/{id}` | 禁用/改角色/重置口令（admin） |

### 2.2 数据集

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/datasets` | 列表，支持 `kind`、`status`、`q` |
| POST | `/api/datasets` | 登记数据集 |
| GET | `/api/datasets/{id}` | 详情（含统计与最近扫描时间） |
| PATCH | `/api/datasets/{id}` | 修改名称/路径/备注 |
| DELETE | `/api/datasets/{id}` | 删除（被任务引用时返回 1005） |

| GET | `/api/datasets/{id}/episodes` | episode 分页检索（`scene`、`q`、`min_len`、`max_len`） |
| GET | `/api/datasets/{id}/episodes/{eid}/observations` | 多源观测时间轴数据 |
| GET | `/api/datasets/{id}/episodes/{eid}/pointcloud` | 局部点云俯视预览（PNG 或点数组） |
| POST | `/api/datasets/{id}/validate` | 质量校验，返回问题清单 |
| GET | `/api/datasets/{id}/splits` | 切分列表 |
| POST | `/api/datasets/{id}/splits` | 生成切分（kind/seed/过滤条件） |
| DELETE | `/api/splits/{id}` | 删除切分 |
| POST | `/api/datasets/{id}/export-causal` | 导出因果切片 jsonl，返回文件下载地址 |

### 2.4 任务

## 3. 关键接口示例

### 3.1 创建任务

```http
POST /api/tasks
```

```json
{
  "name": "vision_geo_state_spatial_prune_seed42",
  "dataset_id": 1,
  "split_id": 4,
  "model_profile_id": 1,
  "template_id": 4,
  "overrides": { "history_len": 8, "prune_ratio": 0.35, "seed": 42 },
  "priority": 5,
  "note": "消融：视觉+几何+状态"
}
```

响应：

```json
{
  "code": 0,
  "data": {
    "id": 12,
    "status": "queued",
    "progress_total": 1839,
    "config_snapshot": { "modality": "vision_geo_state", "...": "..." }
  }
}
```

因果性预检失败：

```json
{ "code": 1006, "message": "输入 rgb_future 不在白名单 [rgb,depth,pose,action]" }
```

### 3.2 SSE 事件流

`GET /api/tasks/12/events`（`text/event-stream`）

```
event: progress
data: {"done": 137, "total": 1839, "episode": "scene001_42", "percent": 7.4}

event: sample
data: {"step": 137, "gpu_mem_mb": 18342, "latency_ms": 412.5, "ctx_len": 9216}

event: log
data: {"level": "info", "text": "[137/1839] scene001_42 SR=1 SPL=0.71 NE=3.42"}

event: state
data: {"status": "paused", "reason": "user"}

event: done
data: {"status": "succeeded", "metrics": {"sr": 0.5661, "spl": 0.5023, "ne": 4.8626}}
```

`progress` 节流为 ≥500ms 一次；`log` 按行推送并落盘 `storage/runs/{task_id}/run.log`。

### 3.3 回放数据

`GET /api/replay/12/137`

```json

  "episode": {
    "episode_key": "scene001_42",
    "instruction": "Walk past the kitchen and stop at the top of the stairs",
    "instruction_tokens": [[0, 4], [5, 9], [10, 14]],
    "start_pose": [1.2, 0.0, 3.4, 0.0],
    "goal_pose": [5.8, 0.0, -2.1, 0.0]

      "latency_ms": 388.2, "window_len": 4, "slow_update": false,
```

### 3.5 报告生成

```json
POST /api/reports
{ "task_ids": [12, 13, 14], "format": "md",
  "include": ["summary", "metrics", "figures", "failures"], "top_failures": 10 }
```

响应直接返回已生成的产物元数据（`id`、`name`、`format`、`size_bytes`），随后通过 `GET /api/reports/{artifact_id}/download` 下载文件。报告同步生成，无需轮询。
